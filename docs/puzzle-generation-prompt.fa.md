# پرامپت ساخت جدول کلمات متقاطع فارسی ۸×۸

این چهار مقدار را در متن پرامپت تغییر دهید:

- موضوع: `[موضوع جدول]`
- سطح: `[آسان / متوسط / دشوار]`
- شناسهٔ انگلیسی یکتا: `[برای مثال science-02]`
- عنوان فارسی: `[عنوان جدول]`

## پرامپت آمادهٔ کپی

```text
تو یک طراح حرفه‌ای جدول کلمات متقاطع فارسی هستی. یک جدول سنتی فارسی ۸×۸ با موضوع «[موضوع جدول]» و سطح «[سطح دشواری]» تولید کن.

خروجی باید فقط یک JSON معتبر باشد. قبل یا بعد از JSON هیچ توضیح یا Markdown ننویس.

قواعد:

1. مقدار version برابر 1، مقدار size برابر 8، مقدار id برابر «[شناسهٔ انگلیسی یکتا]» و مقدار title برابر «[عنوان فارسی]» باشد.
2. جدول باید حداقل 40 خانهٔ سفید داشته باشد و در هر سطر و ستون حداقل 4 خانهٔ سفید وجود داشته باشد.
3. شماره‌های افقی، سطرهای 1 تا 8 از بالا به پایین هستند.
4. شماره‌های عمودی، ستون‌های 1 تا 8 از راست به چپ هستند.
5. هر سطر یا ستون می‌تواند چند واژه داشته باشد که با خانهٔ بسته از هم جدا می‌شوند.
6. هر خانهٔ سفید باید دقیقاً عضو یک واژهٔ افقی و یک واژهٔ عمودی باشد.
7. همهٔ حروف محل تقاطع باید دقیقاً یکسان باشند.
8. واژهٔ افقی از row و col به سمت چپ حرکت می‌کند؛ یعنی col برای هر حرف یک واحد کم می‌شود.
9. واژهٔ عمودی از row و col به سمت پایین حرکت می‌کند؛ یعنی row برای هر حرف یک واحد زیاد می‌شود.
10. مقدار row و col از صفر شروع می‌شود و باید بین 0 تا 7 باشد.
11. number برای across برابر row + 1 است.
12. number برای down برابر 8 - col است.
13. شناسهٔ افقی‌ها باید مانند h1a و h1b و شناسهٔ عمودی‌ها باید مانند v1a و v1b باشد.
14. answer فقط شامل حروف فارسی و حداقل 2 حرف باشد؛ بدون فاصله، نیم‌فاصله، عدد، اعراب یا خط تیره.
15. clue باید فارسی، ساده، روشن و متناسب با answer باشد.
16. همهٔ شماره‌های 1 تا 8 در هر دو جهت across و down باید وجود داشته باشند.
17. entries ابتدا بر اساس افقی‌های 1 تا 8 و سپس عمودی‌های 1 تا 8 مرتب شوند.
18. شبکه باید متصل و در سراسر جدول پخش باشد، نه دو تکه یا متمرکز در یک گوشه.
19. تمام answerها و clueها را برای همین جدول از نو تولید کن. تغییر عنوان یا بازنویسی سرنخ‌های یک جدول قبلی کافی نیست.
20. هیچ answer یا clue تکراری در همین جدول نباشد.
21. هر clue باید فقط و دقیقاً به answer خودش برسد؛ از سرنخ نادرست، ساختگی، مبهم یا نامرتبط استفاده نکن.
22. از واژه‌های واقعی، رایج و دارای املای معیار فارسی استفاده کن. برای سطح آسان، نام‌های بسیار تخصصی و واژه‌های مهجور را به کار نبر.
23. اگر فهرست «پاسخ‌های استفاده‌شده در جدول‌های قبلی» در ادامه داده شد، هیچ‌یک از آن پاسخ‌ها را دوباره استفاده نکن.

پاسخ‌های استفاده‌شده در جدول‌های قبلی:

[در صورت نیاز، پاسخ‌های جدول‌های قبلی را اینجا قرار دهید]

ساختار خروجی:

{
  "version": 1,
  "id": "[شناسهٔ انگلیسی یکتا]",
  "title": "[عنوان فارسی]",
  "description": "توضیح کوتاه فارسی دربارهٔ موضوع و سطح جدول",
  "size": 8,
  "entries": [
    {
      "id": "h1a",
      "number": 1,
      "direction": "across",
      "row": 0,
      "col": 6,
      "answer": "نمونه",
      "clue": "سرنخ فارسی"
    }
  ]
}

قبل از پاسخ، کنترل کن که:

- همهٔ مختصات بین 0 تا 7 باشند.
- حروف تمام تقاطع‌ها برابر باشند.
- هر خانهٔ سفید یک مالک across و یک مالک down داشته باشد.
- شماره‌های 1 تا 8 در هر دو جهت کامل باشند.
- شبکه یکپارچه باشد و کل صفحه را پوشش دهد.
- همهٔ پاسخ‌ها واژهٔ واقعی و از پاسخ‌های جدول‌های قبلی متفاوت باشند.
- هر سرنخ را با پاسخ خودش دوباره بخوان و درستی معنایی آن را تأیید کن.
- خروجی با JSON.parse قابل خواندن باشد.

اکنون فقط JSON نهایی را برگردان.
```

## استفاده در برنامه

1. خروجی مدل را بدون متن اضافی در یک فایل با پسوند `.json` ذخیره کنید؛ برای مثال `science-02.json`.
2. فایل را داخل پوشهٔ `content/puzzles` قرار دهید.
3. دستور `npm run dev` را دوباره اجرا کنید.
4. برای کنترل نهایی، دستور `npm run build` را اجرا کنید.
5. جدول جدید از منوی «انتخاب جدول» قابل انتخاب است.

اگر فایل معتبر نباشد، build متوقف می‌شود و محل خطا را نمایش می‌دهد.
