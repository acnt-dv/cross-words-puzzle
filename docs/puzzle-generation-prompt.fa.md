<h2 dir="rtl" lang="fa">پرامپت آمادهٔ کپی</h2>

<pre dir="rtl" lang="fa"><code>تو یک طراح حرفه‌ای جدول کلمات متقاطع فارسی هستی. یک جدول سنتی فارسی ۸×۸ با موضوع «[موضوع جدول]» و سطح «[سطح دشواری]» تولید کن.

خروجی باید فقط یک شیء JSON معتبر باشد؛ هیچ توضیح، Markdown یا code fence قبل و بعد آن ننویس.

قواعد قطعی:
۱. مقدار version برابر 1، مقدار size برابر 8، مقدار id برابر «[شناسهٔ انگلیسی یکتا]» و title برابر «[عنوان فارسی]» باشد.
۲. شبکه باید کل سطح جدول را پوشش دهد: حداقل 40 خانهٔ سفید، خانه‌های بستهٔ پراکنده، و حداقل 4 خانهٔ سفید در هر سطر و ستون.
۳. افقی‌ها سطرهای 1 تا 8 از بالا به پایین‌اند. عمودی‌ها ستون‌های 1 تا 8 از راست به چپ‌اند.
۴. هر سطر یا ستون می‌تواند چند واژه داشته باشد. بخش‌ها با خانهٔ بسته از هم جدا می‌شوند.
۵. هر خانهٔ سفید باید دقیقاً عضو یک بخش افقی و یک بخش عمودی باشد. هیچ خانهٔ سفید تک‌جهته یا جداافتاده مجاز نیست.
۶. همهٔ حروف تقاطع باید دقیقاً برابر باشند. قبل از خروجی، کل ماتریس ۸×۸ را در ذهن بازسازی و کنترل کن.
۷. واژهٔ افقی از مختصات row,col به سمت چپ حرکت می‌کند؛ یعنی col در هر حرف یک واحد کم می‌شود.
۸. واژهٔ عمودی از مختصات row,col به سمت پایین حرکت می‌کند؛ یعنی row در هر حرف یک واحد زیاد می‌شود.
۹. row و col صفرمبنا و بین 0 تا 7 هستند.
۱۰. number برای across باید row + 1 باشد. number برای down باید 8 - col باشد.
۱۱. id بخش‌های افقی به شکل h1a، h1b و ... و بخش‌های عمودی به شکل v1a، v1b و ... باشد و تکراری نباشد.
۱۲. answer فقط حروف استاندارد فارسی داشته باشد؛ بدون فاصله، نیم‌فاصله، اعراب، خط تیره یا عدد و با حداقل 2 حرف.
۱۳. clue فارسی، روشن، غیرمبهم و متناسب با answer باشد. تا جای ممکن واژه‌ها با موضوع جدول مرتبط باشند، اما صحت تقاطع‌ها اولویت مطلق دارد.
۱۴. هر هشت شمارهٔ افقی و هر هشت شمارهٔ عمودی باید حداقل یک بخش داشته باشند.
۱۵. entries را ابتدا به‌ترتیب افقی‌های 1 تا 8 و سپس عمودی‌های 1 تا 8 مرتب کن.

ساختار دقیق خروجی:
{
  "version": 1,
  "id": "[شناسهٔ انگلیسی یکتا]",
  "title": "[عنوان فارسی]",
  "description": "توضیح کوتاه فارسی دربارهٔ موضوع و سطح جدول",
  "size": 8,
  "entries": [
    {
      "id": "h1a",
      "number": 1,
      "direction": "across",
      "row": 0,
      "col": 6,
      "answer": "نمونه",
      "clue": "سرنخ فارسی"
    }
  ]
}

کنترل نهایی اجباری پیش از پاسخ:
- تمام مختصات داخل 0 تا 7 باشند.
- همهٔ تقاطع‌ها حرف یکسان داشته باشند.
- هر خانهٔ سفید دقیقاً دو مالک داشته باشد: یک across و یک down.
- شماره‌های مستقل 1 تا 8 در هر دو جهت کامل باشند.
- شبکه متصل و در سراسر صفحه پخش باشد، نه دو تکه یا متمرکز در یک گوشه.
- JSON با JSON.parse قابل خواندن باشد.

اکنون فقط JSON نهایی را برگردان.</code></pre>
